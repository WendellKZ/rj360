# Roadmap

## Fase 1 - MVP (atual)

- [x] Cadastro de empresas, contatos e processos de RJ
- [x] Marcos da Lei 11.101/2005 e geracao automatica de prazos
- [x] Agenda de prazos com alerta de vencimento
- [x] Linha do tempo, credores, documentos e parcelas do plano
- [x] Portal do cliente com visibilidade controlada
- [x] Funil de prospeccao com conversao de lead em cliente
- [x] Painel com indicadores

## Fase 2 - Automacao

- [x] Integracao com a API publica do CNJ/DataJud para importar movimentacoes
- [x] Notificacoes por e-mail de prazos a vencer (tarefa agendada)
- [ ] Agendamento automatico do sync_datajud (sem depender do agendador do SO)
- [x] Importacao do quadro de credores por planilha
- [ ] Relatorio mensal de atividades em PDF
- [ ] Registro de auditoria (quem alterou o que)

## Fase 3 - Escala

- [ ] Multiplas consultorias no mesmo sistema (multi-tenant real)
- [ ] Dashboard financeiro do cumprimento do plano por classe
- [ ] Assinatura eletronica de documentos
- [ ] App/Portal responsivo com notificacoes push
- [ ] API para escritorios parceiros

## Ideias para avaliar

- Captura de leads a partir de publicacoes de RJ nos diarios oficiais
- Simulador de viabilidade do plano (fluxo de caixa projetado x parcelas)
- Modelo de pontuacao de risco de convolacao em falencia
